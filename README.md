# Rockstreamer

Rockstreamer is a React 18 video-discovery frontend with React Router 5 and a streaming-inspired interface.

## Live site

[Open the deployed website](https://youtube-clone-mmn7.vercel.app/)

## Local development

Install Node.js and npm:

```bash
npm install
npm start
```

Visit the local address printed by the development server (typically http://localhost:3000).

## Scripts

- `npm start` — development server
- `npm run build` — production build
- `npm test` — run configured test runner

## Notes

External video data may depend on third-party API availability and configuration.
